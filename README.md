## ☀️ Works with ComfyUI

 🙌 Launch ComfyUI and install the ShellAgent-Plugin

- Download or `git clone` the contents of the https://github.com/myshell-ai/ComfyUI-ShellAgent-Plugin repository to the `ComfyUI/custom_nodes/` directory.
- The custom_nodes directory is installed using the `git clone https://github.com/myshell-ai/ComfyUI-ShellAgent-Plugin.git`  command
- Use `pip install -r requirements.txt` in the ShellAgent-Plugin directory to install dependencies
